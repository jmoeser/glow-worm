# Shares

Read this before changing share trades, FIFO cost base, prices, or FX. `AGENTS.md` only points here. Shares do not post household transactions. The `share_market_data` job and `SHARES_CATCHUP_ON_STARTUP` catch-up are under Scheduler in `docs/monthly-processing.md`. Never log Alpha Vantage request URLs; the redaction rules are in Common Pitfalls in `AGENTS.md`.

## Shares

FIFO only, ordered by `(trade_date, id)`. Cost base and proceeds for USD trades are converted with the broker FX rate stored as AUD per USD. Frankfurter is the primary daily AUD/USD source; Alpha Vantage `FX_DAILY` is the fallback. US prices use Alpha Vantage `TIME_SERIES_DAILY` when `ALPHA_VANTAGE_API_KEY` is set. The key is redacted from logs and run messages. A missing key skips prices and still fetches FX. Failed price calls keep the last good close and its `as of` date. Hard-deleting a buy that would make a later sell an oversell is rejected. `.AX` / `.AUS` tickers are accepted as AUD instruments (no FX, fee currency forced to AUD) so the provider interface can grow; v1 does not price ASX symbols. `/shares` charts portfolio market value and FIFO cost base in AUD (`build_portfolio_series`). A point is drawn only when every open holding has a stored close on or before that day, carrying the last close and AUD/USD rate across gaps. The 1M/3M/6M/1Y/All toggle filters that series in the browser with the same calendar-month window as `filter_portfolio_series`. The chart reuses D3, already loaded from `d3js.org` for the income Sankey. Fewer than two valued days shows an empty state.
